## Projetos em destaque

### NutriChat — Assistente nutricional via WhatsApp

<div align="center">

<a href="https://nutrichat-landing-six.vercel.app">
  <img src="https://img.shields.io/badge/Landing-nutrichat--landing--six.vercel.app-8b5cf6?style=for-the-badge&logo=vercel&logoColor=white" alt="landing"/>
</a>
<a href="https://github.com/GabrielBotelhoeng/Nutri_Fit">
  <img src="https://img.shields.io/badge/C%C3%B3digo-Nutri__Fit-181717?style=for-the-badge&logo=github&logoColor=white" alt="repo"/>
</a>

</div>

Assistente nutricional white-label que roda no WhatsApp. O paciente conversa por texto, áudio, foto do prato ou código de barras, e o bot registra refeições, calcula TMB, hidrata, envia lembretes e responde dúvidas sobre a dieta com **RAG** em cima do PDF do plano.

- **Backend:** Node.js + TypeScript + Express, agente orquestrado com **Claude Sonnet 4.6**
- **Voz e visão:** **Groq Whisper** pra transcrição de áudio + **Vision** pra análise de foto do prato
- **RAG:** pgvector no Supabase indexando o plano alimentar em PDF
- **WhatsApp:** integração com **Evolution API v2** (Baileys sob o capô)
- **Automação:** **N8N** disparando lembretes de refeição, água, suplemento e relatório semanal
- **Painel:** React + Vite pra nutricionista cadastrar paciente e acompanhar aderência
- **Deploy:** Fly.io (backend + Evolution + N8N) + Vercel (painel + landing) + Supabase (dados)

**Stack completa:** `TypeScript` `Node.js` `Express` `React` `Vite` `Postgres` `pgvector` `Supabase` `Docker` `Fly.io` `Vercel` `Claude API` `OpenAI` `Groq` `N8N` `Evolution API`
